# 静的リソース バージョン管理規約

## キャッシュ対策

- HTMLファイルで `style.css` / `main.js` などの静的リソースを読み込んでいるか？ → **Yes**: クエリパラメータ `?v=YYYYMMDD.x` を付与する
  - 例: `<script src="main.js?v=20260410.1"></script>`

## 更新ルール

- CSS / JS ファイルを修正したか？ → **Yes**: 読み込み元HTMLのバージョン番号を修正日の日付（`YYYYMMDD`）に更新する

## インクリメントルール

- 同日に既にバージョン番号が更新されているか（日付が同じ）？ → **Yes**: 末尾の数字 `.x` を1増やす
  - 例: `20260410.1` → `20260410.2`
- 別日の更新か？ → **Yes**: 日付を新しい日付にリセットし、末尾を `.1` にする
  - 例: `20260409.3` → `20260410.1`
