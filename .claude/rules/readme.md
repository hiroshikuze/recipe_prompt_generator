# README 作成規約

## 言語

- READMEの記述言語は日本語を基本とする。ただし以下は英語固定:
  - `Recipe Prompt Generator.`（Descriptionセクション）
  - `This tool suggests prompts to ask AI to generate cooking recipes.`（冒頭説明）

## 視認性

- 仕様を一目で把握できるか？ → **No**: 表形式（Tables）やチェックボックスを活用する

## 情報更新

- コーディングによってREADMEの記載内容に変更が生じたか？ → **Yes**: 最新のコーディング内容を優先してREADMEを更新する

## リスト形式

- markdownリストが `-` 以外の記号（`*` など）を使っているか？ → **Yes**: `-` に統一する
  - 番号付きリスト（`1.`）は用途に応じて許可
